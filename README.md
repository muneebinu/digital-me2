## Run locally

No build step or package installation is required.

1. Clone this repository:
   ```bash
   git clone https://github.com/muneebinu/muneebinu.github.io.git
   cd muneebinu.github.io
   ```
2. Open `index.html` in a browser, or serve the folder with a local static server.
3. The page loads some visual libraries and fonts from third-party CDNs, so an internet connection is needed for those features.

## Accessibility and performance notes

The site includes responsive layouts, semantic page landmarks, a skip link, accessible navigation state, and reduced-motion handling. Some animation and visual effects depend on third-party CDN libraries and browser capabilities.

## SEO and AI discovery

The site includes a descriptive page title and meta description, canonical URL, Open Graph and Twitter metadata, Schema.org structured data for the profile, a sitemap, crawler guidance, and an `llms.txt` summary for AI systems. These help systems understand the site but do not guarantee indexing, rankings, or citations.
